# E-Commerce Sales Analysis – Power BI Dashboard

## About the Project

This is my first Power BI assignment. I built a dashboard to show how an online store in India performed in 2018, using 500 orders.

## Tools Used

- Power BI
- Microsoft Excel

## What I Did

- Imported the two Excel files into Power BI and linked them using the Order ID.
- Added cards showing total amount, total profit, total quantity and average order value (AOV).
- Built charts showing:
  - Total amount by state
  - Total profit by state
  - Quantity sold by payment mode
  - Quantity sold by category
  - Profit by sub-category
  - Profit by month
- Put everything on one page to make the dashboard easy to read.

## Result

The dashboard makes it easy to see which states bring in the most sales and profit, the best-selling categories, the most used payment methods and how profit changes from month to month.

## What I Learned

This project helped me learn the basics of Power BI. I learned how to connect two tables, create cards and charts, and arrange them into a clear dashboard.
